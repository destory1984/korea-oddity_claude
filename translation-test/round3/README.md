# 번역 시험 3차 (이름표로 채우기, 일본어와 중국어)

- 한 날: 2026.10.7
- 1차에서 열 칸 가운데 흠 없는 칸이 3칸이었다. 까닭은 이름이었다. 3차는 이름을 기계에 맡기지 않고 이름표(`docs/이름표.md`)에서 채우면 얼마나 나아지는지 본다.

## 한 일

1. 1차의 원문에서 사실을 적는 글(카드 3줄, 문제 1줄, 가는 길 3줄)만 남겨 열 칸 70줄로 했다. `docs/번역-규칙.md` 4절대로 고쳤다. 들어온다 → 입국한다, 기차 → 열차, 나무 판 → 경판, 서해 → 서쪽 바다. 이름은 `{첨성대}` 처럼 표시로 감쌌다. (`source.json`)
2. 모델 둘(A는 Claude Sonnet, B는 Claude Opus)이 표시를 그대로 둔 채 일본어와 중국어로 옮겼다. (`out-A.json`, `out-B.json`)
3. `node translation-test/round3/fill.mjs` 가 표시를 이름표의 일본어, 중국어로 채웠다. (`filled-A.json`, `filled-B.json`)
4. 원문을 못 본 모델이 채운 글만 보고 한국어로 되돌렸다. (`read-ja.json`, `read-zh.json`)
5. `node translation-test/round3/compare.mjs` 로 나란히 놓고 사람 눈으로 견주었다.

## 결과

| | 1차 | 3차 |
|---|---:|---:|
| 견준 줄(줄 × 말 × 모델) | 202 | 280 |
| 이름이 틀린 줄 | 10 | 0 |
| 뜻이 틀어진 줄 | 2 | 3 |
| 흠 없는 칸(열 칸 가운데) | 3 | 8 |

- 이름 표시는 280줄 모두에서 원문 그대로 남았다. 모델이 표시를 건드리거나 빼먹은 줄이 없다.
- 이름은 이름표에서 왔으므로 두 모델이 같다. 1차에서 갈렸던 한라산, 정동진, 부용대, 장경판전이 모두 한 가지로 나왔다.
- 뜻이 틀어진 3줄은 두 곳에서 나왔다. 하나는 54번 칸의 "해마다 몇 번 갈라진다"다. 두 모델의 중국어가 모두 "每年会分开几次"였고, 되돌려 읽으니 "몇 번 갈라지는가?"라는 물음이 되었다. "몇 번"과 "几次"가 둘 다 "여러 번"과 "몇 번인가"로 읽히기 때문이다. 원문을 "해마다 서너 번"처럼 고쳐야 한다.
- 다른 하나는 38번 칸의 "서쪽 바다"다. A가 중국어로 "西海"라 옮겼다. 바다 이름을 피하려고 쪽으로 적었는데 다시 이름이 되었다. B는 "西边海域"로 옮겼다.
- 한자어로 고친 낱말은 두 모델이 같은 낱말로 옮겼다. 입국한다는 넷 모두 入国, 入境이고, 열차는 列車다. 중국어에서만 列车와 火车가 갈렸다.
- 두 모델의 번역이 글자까지 같은 줄은 70줄 가운데 일본어 38줄, 중국어 23줄이다.

읽은 모델이 어색하다고 짚은 것은 19곳이다. 뜻과는 상관없는 것들이다.

- 이름 셋을 의심했다. 城板岳(성판악), 花地(꽃지), コッチ(꽃지). 셋 다 이름표에서 바탕이 "검색"이나 "어림"인 것이다. 공식 자료로 확인해야 할 이름을 되돌려 읽기가 스스로 짚어 냈다.
- 첨성대를 石塔이라 한 것이 천문대에는 어색하다고 했다. 원문이 "돌탑"이다. 원문을 "돌로 쌓은 천문대"로 고칠지 본다.
- 중국어의 "高约9米"처럼 주어가 없는 줄을 짚었다. 원문도 "높이는 약 9미터이다"로 앞 줄에 기대는 글이다.

## 여기서 나온 것

- 이름표와 표시로 채우는 길이 통한다. 이름 문제가 10줄에서 0줄이 되었다.
- 원문 규칙에 하나를 더한다. "몇 번", "몇 개"처럼 물음으로도 읽히는 말을 평서문에 쓰지 않는다. 숫자나 "여러"로 적는다.
- 이름표의 질이 곧 번역의 질이 된다. 이름표에서 덜 확인된 이름이 읽는 쪽에서도 걸렸다.

## 한계

- 번역한 모델과 읽은 모델이 모두 같은 회사의 것이다.
- 이름표가 위키백과 바탕이다. 틀린 이름이 표에 있으면 두 번역에 똑같이 들어가고, 이 시험으로는 잡히지 않는다.
- 일본어에서 이름 뒤에 붙는 조사가 맞는지(이름을 채운 뒤의 흐름)는 읽는 모델이 한 군데도 짚지 않았지만, 사람이 확인한 것은 아니다.
- 원문의 사실(해, 높이, 가는 길)은 여전히 초안이다.
