# 바뀐 것들: 날마다 한 일

나중에 게임 안에 "바뀐 것들" 쪽을 만들 때 쓸 자료다. 우주 한량(1권)의 `src/core/changes.js`, 시간 한량(2권)의 `docs/바뀐-것들.md` 와 같은 쓰임이다.

## 적는 법

- 한 줄에 하나, 쉬운 말로 적는다. 새 날이 위에 오고, 같은 날 안에서도 새 줄이 위에 온다.
- 줄은 게임에 그대로 들어갈 글이라 "습니다"로 끝낸다.
- 게임이 생기기 전(지금)에는 무엇을 정하고 만들었는지를 적는다. 게임이 생긴 뒤에는 화면에 보이거나 귀에 들리는 것만 적는다.
- 숫자를 넣는다. 사실 확인으로 고친 것은 무엇이 무엇으로 바뀌었는지 적는다.
- 눈에 띄는 일을 하나 마치면 그날 맨 위에 한 줄을 더한다. 커밋할 때 함께 넣는다.
