# 그래픽 발주서 3: 비교 시제품 둘째 판의 그림 7장

비교 시제품의 둘째 판(부석사, 소백산 천문대)에 쓸 그림을 주문했다. 사용자의 말(2026.10.10): "그림은 gpt한테 외주 줘서, 예쁘게 만들어".

- 쓴 날: 2026.10.10. 받은 날: 2026.10.10
- 그리는 손: 챗GPT의 그림 그리기. Codex CLI로 넣었다(`tools/art-order.sh`).
- 주문한 것: 부석사의 네 계절 4장, 소백산 천문대의 세 지점 3장. 7장 모두 한 번에 받았고 다시 주문한 것은 없다.

## 1. 발주서 1, 2와 달라진 것

| 무엇 | 발주서 1, 2 | 발주서 3 |
|---|---|---|
| 한 자리의 그림 | 앞뒤로 나눈 겹 3 → 4장 | 한 장면을 통째로 그린 1장 |
| 빈 자리 | 그릴 것이 없는 자리 모두 `#ff00ff` | 하늘만 `#ff00ff`. 게임이 하늘, 해, 별을 그린다 |
| 계절 | 받은 그림의 색만 바꿔 넉 장을 만든다 | 계절마다 따로 받는다. 같은 구도로 넉 장 |
| 지점 | 같은 겹을 키우거나 밀어 만든다 | 지점마다 따로 받는다 |
| 공들임 | 겹마다 한 가지 색 | 종이 겹을 많이 쓰고 작은 것까지 오려 붙인다 |

겹으로 나누지 않은 까닭은 둘이다. 부석사는 자리를 고르지 않는 판이라 겹이 서로 밀릴 일이 없다. 소백산은 지점이 셋뿐이라 지점마다 한 장을 받는 편이 곱다.

계절을 따로 받으니 색 바꾸기로는 안 되던 것이 된다. 겨울에는 지붕과 석등에 눈이 쌓이고, 봄에는 산벚꽃이 핀다.

## 2. 주문한 7장

| 파일 | 장소 | 무엇 | 묘사 |
|---|---|---|---|
| `bus-autumn` | 부석사 | 늦가을 | 무량수전 앞마당에서 남쪽을 내려다본 풍경. 왼쪽에 무량수전의 기둥 둘과 처마, 가운데에 석등, 그 뒤에 안양루의 기와지붕, 지붕 너머로 단풍 든 능선 일곱 겹, 오른쪽에 큰 단풍나무의 가지 |
| `bus-spring` | 부석사 | 봄 | 같은 구도. 연둣빛 새잎과 산벚꽃 |
| `bus-summer` | 부석사 | 여름 | 같은 구도. 짙고 무성한 초록 |
| `bus-winter` | 부석사 | 겨울 | 같은 구도. 처마, 지붕, 석등, 돌축대, 마당에 눈. 나무는 눈 얹힌 맨 가지 |
| `sobaek-b` | 소백산 천문대 | 능선 위(넓은 구도) | 누런 풀과 바위의 능선 위에 흰 돔 건물, 그 옆에 작은 돔, 뒤로 겹겹의 먼 산. 그림의 위쪽 절반이 하늘 |
| `sobaek-a` | 소백산 천문대 | 돔 앞(가까이) | 돔 건물 바로 앞에서 올려다본 구도. 돔의 윗부분이 그림 밖으로 잘린다 |
| `sobaek-c` | 소백산 천문대 | 가로등 밑 | 넓은 구도와 거의 같은 거리. 왼쪽에 가로등 하나가 크게 선다. 불빛은 게임이 그린다 |

묘사는 지어 쓴 것이다. 부석사에서 보이는 능선의 모양, 소백산 천문대의 건물과 가로등은 사진과 견주지 않았다.

## 3. AI에 넣은 문장

앞머리(그림체와 지킬 것)다. 발주서 1의 앞머리에서 그림체의 대목을 바꾸었다.

```text
크기 1536x1024(가로), PNG.

그림체: 색종이를 오려 겹친 듯한 납작한 그림. 윤곽선 없음. 번지는 색, 붓 자국, 사진 같은 질감 없음.
이번 그림은 게임의 한 장면을 통째로 맡는 그림이라 공을 많이 들일 것:
- 종이 겹을 많이 쓴다. 큰 덩어리만 그리지 말고 작은 것까지 오려 붙인다(기와의 골, 창살, 돌의 이음, 나뭇가지와 잎 덩어리, 풀포기).
- 겹마다 한 가지 색으로 고르게 칠하되, 한 사물 안에서도 밝은 색과 어두운 색 서너 단계를 겹쳐 깊이를 준다.
- 겹 사이에 옅은 그림자를 두어 종이가 떠 있는 느낌을 낸다. 종이의 결이 아주 은은하게 보여도 좋다.
- 먼 것은 옅고 푸르게, 가까운 것은 짙고 또렷하게.
- 색은 차분하고 고운 한국의 색. 너무 쨍하지 않게.

지킬 것:
- 하늘은 모두 #ff00ff(자홍색) 한 가지 색으로 고르게 칠할 것. 게임이 하늘과 해와 별을 따로 그린다.
- 한낮의 고른 빛으로. 노을빛, 밤, 긴 그림자, 불 켜진 창을 넣지 말 것. 게임이 저녁과 밤의 빛을 입힌다.
- 사람, 사람의 얼굴, 글자, 숫자, 현판의 글씨를 넣지 말 것.
- 자홍색(#ff00ff)이나 그와 비슷한 분홍, 보라를 그림 안에 쓰지 말 것.
- 그림의 왼쪽 끝과 오른쪽 끝, 맨 아래까지 빈 데 없이 그릴 것.
```

같은 구도로 계절만 바꿀 때 붙인 말이다. 먼저 받은 가을 그림을 참고 그림으로 넣었다.

```text
참고 그림 bus-autumn.png 는 같은 자리의 늦가을 그림이다. 이 그림과 구도, 무량수전의 기둥과 처마, 석등, 안양루의 지붕,
돌축대, 마당, 능선의 윤곽, 나무가 선 자리와 가지의 꼴을 그대로 두고 계절만 바꿔 다시 그릴 것. 게임이 네 계절의 그림을
겹쳐 녹이므로 사물의 자리와 크기가 어긋나면 안 된다. 하늘의 자홍색 자리도 같은 꼴이어야 한다.
```

지점만 옮길 때 붙인 말이다. 먼저 받은 넓은 구도를 참고 그림으로 넣었다.

```text
참고 그림 sobaek-b.png 는 같은 천문대를 조금 떨어져서 본 그림이다. 건물과 돔의 생김새, 풀과 바위와 떨기나무의 그림체,
색을 이 그림과 똑같이 맞출 것. 같은 날 같은 곳에서 자리만 옮겨 본 그림이어야 한다.
```

## 4. 주문한 차례

1. 기준이 될 두 장(`bus-autumn`, `sobaek-b`)을 먼저 받아 눈으로 보았다.
2. 그 둘을 참고 그림으로 넣어 나머지 다섯 장을 주문했다. 작업 폴더를 장마다 따로 두고 셋을 한꺼번에 돌렸다. 한 장에 2 → 3분 걸렸다.
3. `tools/key-sky.py` 로 하늘의 자홍색을 지우고 `docs/assets/scenes/` 에 WebP로 두었다. 부석사는 `bus2-<계절>.webp`, 소백산은 `sobaek-<지점>.webp` 다.

## 5. 받고 확인한 것

| 확인 | 결과 |
|---|---|
| 하늘이 한 가지 자홍색인가 | 7장 모두 그렇다. 나뭇가지 사이의 하늘도 같다 |
| 글자, 숫자, 사람이 없는가 | 없다 |
| 계절 넉 장의 구도가 같은가 | 같다. 기둥, 석등, 지붕, 돌축대, 능선의 윤곽이 포개진다. 겨울은 처마에 눈이 얹혀 윤곽이 조금 두껍다 |
| 봄의 분홍 꽃이 하늘과 함께 지워지지 않았는가 | 지워지지 않았다. 그림 아래쪽 절반에 뚫린 데가 없다 |
| 지점 석 장이 같은 천문대로 보이는가 | 그렇다. 돔의 틈, 흰 벽, 가운데의 큰 창이 석 장에서 같다. 가까운 구도는 주문대로 돔의 꼭대기가 그림 밖으로 잘렸다 |
| 지난 발주보다 고운가 | 그렇다. 기와의 골, 공포, 창살, 돌축대의 돌, 풀포기까지 그려졌다 |

## 6. 아직 보지 않은 것

- 부석사와 소백산 천문대의 생김새가 사실과 맞는지. 사진과 견주지 않았다.
- 그림이 촘촘해져 파일이 커졌다(가을 한 장이 381KB. 발주서 1의 겹은 한 장에 15 → 40KB였다). 손전화의 느린 망에서 얼마나 걸리는지 보지 않았다.
- 사용자가 이 그림체를 좋다고 하는지.
