# 그림 주문 11: 엷은 수채의 명동 석 장 (2026.10.12)

수채 견본(`docs/water/`)에 쓰는 그림이다. 사용자가 본보기를 Dordogne(2023)으로 정했고, 그림체를 수채로, 계절을 가을로 정했다.

## 1. 받은 것

| 그림 | 쓰는 곳 | 원본 |
|---|---|---|
| `docs/water/art/md-exit.webp` | 명동역 대합실. 계단 셋(왼쪽, 가운데 안쪽, 오른쪽), 안내도 판, 가게 둘 | `assets/codex/order11-md-exit/w-md-exit.png` |
| `docs/water/art/md-wrong.webp` | 3번 출구로 나온 산 쪽 찻길 | `assets/codex/order11-md-wrong/w-md-wrong.png` |
| `docs/water/art/md-street.webp` | 명동 거리. 왼쪽 위에 탑, 오른쪽 앞에 계란빵 수레 | `assets/codex/order11-md-street/w-md-street.png` |

석 장 모두 한 번에 받았다. 원본은 1536×1024이고 960×640의 WebP(품질 82)로 줄였다. 석 장이 414KB다(한 장에 96 → 163KB). 색연필 때(한 장에 220 → 259KB)보다 가볍다.

## 2. 주문한 말

앞머리는 `assets/codex/order11/_head-w.txt`, 장면마다의 말은 같은 폴더의 `md-exit.txt`, `md-wrong.txt`, `md-street.txt` 다(저장소에 올리지 않는 폴더다). 앞머리의 알맹이를 여기 옮긴다.

- 여행 수첩에 그린 수채 그림. 연필의 가는 선 위에 맑은 수채 물감을 엷게 얹었다.
- 물을 많이 쓴 엷은 칠. 색이 가장자리에서 번지고 종이의 결과 물 자국이 보인다.
- 흰 종이를 많이 남긴다. 그림의 3분의 1쯤은 칠하지 않았거나 아주 엷다.
- 색을 묶는다. 바탕은 크림색 종이와 엷은 회청색 그늘이다. 짙은 색은 장면마다 적은 한두 군데에만 쓴다.
- 윤곽은 연필의 가늘고 조금 흔들리는 선. 굵은 검은 테두리는 쓰지 않는다.

장면마다 "짙은 색을 쓸 곳"을 한 줄로 적었다. 대합실은 계단 끝의 햇빛과 빨간 차양 하나, 찻길은 단풍의 주황, 거리는 수레의 빨간 차양과 은행나무의 노랑이다.

## 3. 배운 것

- 참고 그림 없이 주문하면 그리는 쪽이 멈춘다. `tools/art-order.sh` 가 "참고 그림을 먼저 보라"는 말을 앞에 붙이기 때문이다. 석 장이 모두 빈손으로 돌아왔다. 같은 곳을 그린 옛 그림(색연필)을 참고로 넣고 "무엇이 있는 곳인지만 참고하고 그림체와 색은 따르지 않는다"고 적어 다시 주문했다.
- 수채 견본 `assets/codex/order9-md-p1/md-p1.png` 는 원색이 가득했다. "밝고 따뜻하게"를 빼고 바탕색과 짙은 색 둘을 적었더니 엷게 왔다.
- 누를 것의 자리를 글로 못 박으면 그 자리에 온다("왼쪽 끝에 하나, 가운데 안쪽 멀리에 하나, 오른쪽 끝에 하나"). 출구의 번호판은 그림에 넣지 않고 화면에서 따로 붙였다. 번호를 그림에 넣으면 글자가 깨지고 말을 바꿀 수 없다.
