# 번역 규칙

- 쓴 날: 2026.10.7
- 사용자가 정한 것(2026.10.7): 원어민은 없다. 기계 번역으로 하되 한국어의 느낌을 되도록 살린다.
- 바탕: 1권의 번역(`oddity_claude` 저장소의 `src/i18n/ja.json`, `zh.json`, 3,658줄), 번역 시험 1차(`translation-test/README.md`)와 2차(`translation-test/round2/README.md`)

## 1. 말씨

1권이 옮긴 대로 옮긴다. 소라와 할머니는 세 권에서 같은 사람이다.

| 누구 | 한국어 | 일본어 | 중국어(간체) |
|---|---|---|---|
| 소라 | 반말. "야", "어", "네", "래" | 「だ」「だよ」「てる」「だね」「ちゃった」「んだって」 | "呢", "啦", "呀". "听说"("래") |
| 할머니 "단다" | 알려 주는 말 | 「んだよ」 | "呢" |
| 할머니 "구나" | 알아차린 말 | 「だね」「んだね」 | "呀" |
| 할머니 "하렴", "보렴" | 권하는 말 | 「てごらん」 | "吧" |
| 할머니 "주련" | 부탁하는 말 | 「ておくれ」 | "吧" |
| 할머니의 메모 | 날짜. 날씨. 한 줄 | 끊어 적는다. 「晴れ。」 | 끊어 적는다. "晴。" |

- 할머니는 소라를 "너"라 하지 않고 이름으로 부른다. 일본어는 ソラ, 중국어는 你다. 1권이 그랬다.
- 할머니는 자기를 わたし, 我라 한다.
- 딱딱한 시킴말은 쓰지 않는다. 「せよ」「しなさい」, "请"은 없다.

1권의 본보기다.

| 한국어 | 일본어 | 중국어 |
|---|---|---|
| 다녀와서 얘기해 주련. | 帰ってきたら、話を聞かせておくれ。 | 回来讲给我听听吧。 |
| 답은 "{}". 다음에 또 맞혀 보렴. | 答えは「{0}」。次にまた当ててごらん。 | 答案是“{0}”。下次再来猜猜吧。 |
| 그 붉은 점은 내가 처음 봤을 때보다 작아졌단다. | あの赤い斑点は、わたしが初めて見たころより小さくなったんだよ。 | 那个红斑比我第一次看到的时候小了呢。 |
| 저 점이 지구야? 진짜 작다. | あの点が地球？ほんとに小さい。 | 那个点就是地球？真的好小啊。 |

## 2. 굳은 낱말

1권에서 이미 정해진 것은 그대로 쓴다. 새로 짓지 않는다.

| 한국어 | 일본어 | 중국어 |
|---|---|---|
| 소라 | ソラ | 索拉 (부를 때 小索拉) |
| 할머니 | おばあちゃん | 奶奶 |
| 수첩 | 手帳 | 笔记本 |
| 쪽지 | 書きつけ | 便条 |
| 답장 | 返事 | 回信 |
| 칸 | マス | 格 |

번역을 맡기기 전에 1권의 사전에서 같은 낱말이 있는지 먼저 찾는다.

## 3. 이름

지명, 건물, 사람, 왕조 이름은 기계 번역에 맡기지 않는다. 손으로 확인한 이름표(`docs/이름표.md`)를 쓴다.

- 까닭: 1차 시험에서 부용대가 浮島台로, 정동진이 正東進으로 나왔다. 2차에서는 소라가 小空으로 나왔다. 한자가 틀려도 되돌려 읽으면 소리가 같아 잡히지 않는다.
- 이름표의 한 줄: 한글, 한자(정자), 일본어 표기, 중국어 표기, 확인한 원 자료.
- 일본어에서는 한자 뒤에 읽는 소리를 괄호로 붙인다. 1권이 그랬다. 예: 独島（トクト）.
- 번역할 때는 이름 자리를 `{부용대}` 처럼 표시로 바꿔 넣고, 번역이 끝난 뒤 이름표에서 채운다. 3차 시험에서 이 길로 이름이 틀린 줄이 10줄에서 0줄이 되었다(`translation-test/round3/README.md`).

## 4. 원문을 쓰는 법

기획서 4절의 규칙(한 문장에 한 가지 일, 주어를 빼지 않기, 관용구 없음, 숫자와 고유명사 중심)에 더한다.

- 카드, 문제, 가는 길처럼 사실을 적는 글은 한자어가 있으면 한자어로 쓴다. 들어온다 → 입국한다, 기차 → 열차. 두 모델이 같은 낱말로 옮긴다.
- 소라와 할머니의 말은 한자어로 바꾸지 않는다. 말맛이 죽는다.
- 무엇을 하는지가 빠지면 번역이 흔들린다. "돌리니까 꽃이 피었다 졌다 해"는 중국어에서 "한 바퀴 돌면"이 되었다. 화면에 다이얼이 보이는 자리에서만 쓰거나 "다이얼을 돌리니까"로 쓴다.
- 문제 문장은 "무엇이 무엇을 어찌할까" 차례로 쓴다.
- "몇 번", "몇 개"처럼 물음으로도 읽히는 말을 평서문에 쓰지 않는다. 숫자나 "여러"로 적는다. 3차 시험에서 "해마다 몇 번 갈라진다"가 중국어를 거쳐 "몇 번 갈라지는가?"로 돌아왔다.
- 원문에 괄호 한자를 넣지 않는다. 한자는 이름표가 맡는다.

## 5. 확인하는 법

원어민이 없으니 세 가지를 기계로 본다.

1. 두 모델이 따로 번역한다. 1권의 본보기 38줄(`translation-test/round2/style-ref.json`)을 함께 준다.
2. 원문을 못 본 모델이 번역만 보고 한국어로 되돌린다. 뜻이 원문과 같은지 본다.
3. 같은 모델이 "누가 한 말 같은가"(아이, 어른, 메모)를 짐작한다. 말씨가 살았는지 본다.

뜻이 틀어지면 번역을 고치지 않고 원문을 더 쉽게 고쳐 다시 돌린다. 이름은 이 길로 확인하지 못한다. 이름표를 원 자료와 눈으로 맞춘다.

## 5-1. 영어 (2026.10.7에 더했다)

영어는 1절의 말씨 규칙을 아직 세우지 않았다. 지금 시험판의 영어는 다음 넷만 지켰다.

- 본은 1권의 영어 사전(`src/i18n/en.json`)이다. 같은 낱말은 그대로 가져온다. 설정 Settings, 닫기 Close, 소리 Sound, 배경 음악 Music, 쉬잇 Shh~, 할머니의 수첩 Grandma's Notes, "맞았다. 꼼꼼히 읽었구나." → "Right. You read it with care."
- 이름은 3절과 같이 이름표에서 채운다. 영어 이름은 `docs/이름표.md` 의 영어 절에 있다.
- 한국어 낱말은 국어의 로마자 표기법으로 적고 뜻을 풀어 덧붙이지 않는다. Muryangsujeon 을 Muryangsujeon Hall 로 적지 않는다(전이 이미 Hall 이다).
- 날짜는 12 May 1971 처럼 날, 달, 해의 차례로 적는다. 미터법을 쓴다.

할머니의 "보렴", 소라의 반말을 영어에서 어떻게 살릴지는 정하지 않았다. 되돌려 읽기와 말씨 확인(5절)도 영어로는 하지 않았다.

## 6. 아는 한계

- 중국어는 말끝으로 아이와 어른을 가르기 어렵다. 2차 시험에서 할머니의 말 22줄 가운데 11줄만 어른의 말로 읽혔다. 일본어는 18줄이었다.
- 일본어의 「んだよ」는 아이도 쓴다. "단다"로만 끝나는 짧은 줄은 누구 말인지 가려지지 않는다.
- 그래서 할머니의 말은 손글씨 글꼴과 종이쪽 그림이 함께 맡는다. 글은 고른 말 하나로만 적고(사용자, 2026.10.7), 손글씨 글꼴을 말마다 하나씩 둔다.
- 번역이 자연스러운지는 끝내 알 수 없다. 칸마다 "번역이 어색하면 알려 주렴" 글귀와 이슈 링크를 둔다.
