## 2. 정한 것

- 번역 시험 1차의 결론(2026.10.7): 문장은 기계 번역과 역번역으로 맞출 수 있다. 이름은 못 맞춘다. 지명, 건물, 사람, 왕조 이름은 손으로 확인한 이름표를 쓴다. 규칙 여섯은 `translation-test/README.md` 에 있다.
- **번역은 원어민 없이 기계 번역으로 하고, 한국어의 느낌을 되도록 살린다**(사용자, 2026.10.7). 소라의 반말과 할머니의 말씨를 두 나라 말의 같은 결로 옮긴다. 기획서 4절의 "소라의 말투는 번역에서 지키지 않는다"는 고쳤다. 본은 1권의 `src/i18n/ja.json`, `zh.json`(3,658줄)이다. 규칙은 `docs/번역-규칙.md` 에 있다.
- 시험판의 계절 다이얼: 눈금 한 칸(12픽셀)이 5일, 73칸이 한 해. 움직임과 소리는 2권 다이얼 그대로다. 사용자가 손으로 보고 정해야 굳는다.

## 3. 아직 정하지 않은 것

1. **사진 포개기의 손맛.** 시험판을 사용자가 손전화로 만져 보고 답해야 한다. 물을 것은 넷이다. 포개는 일이 재미있는가, 너무 쉽거나 어려운가(지금은 14픽셀 안에서 끌려간다), 반투명 사진이 풍경을 가리지 않는가, 다이얼과 날기의 손가락이 부딪치지 않는가.
2. **다이얼에 절기 한자를 적는 것.** 기획서에 없던 것을 시험판에 넣어 보았다. 세 나라가 같이 읽는 글자라는 까닭이다. 둘지 뺄지 정한다.
3. **시험판을 손전화로 여는 길.** 저장소가 비공개라 GitHub Pages를 쓸 수 없다(무료 요금제). 공개로 돌리거나, 파일을 손전화로 보내 열거나, 시험판만 다른 공개 저장소에 둔다.
4. **이름표의 네 가지**(`docs/이름표.md` 끝). 조선을 朝鮮王朝로 적는가, 바다 이름(서해, 동해)을 어떻게 적는가, 일본어 읽기를 한국어 소리로 통일하는가, 팔만대장경의 이름.
4. **기획서 15절의 아홉 가지.** 제목, 세 나라 사이의 자리 넷, 번체, 칸 수, 가는 길의 출발점 들이다.
5. **할머니의 답장 글자 수.** 답장은 일본어로 옮기면 25자를 넘는다(2차 시험에서 가장 긴 줄이 33자). 답장만 한도를 따로 둘지 정한다.
6. **글자 수를 세는 법.** 메모 25자에 띄어쓰기와 날짜를 넣어 세는가. 기획서 6절의 본보기 메모는 넣어 세면 50자가 넘는다. 2권은 화면 메모(25자)와 수첩 메모(60자)로 나누었다.

## 4. 찾아낸 문제

- 기획서 13절은 "1권, 2권이 한국어판뿐"이라 했는데 사실이 아니었다. 1권은 네 나라 말이 있다. 기획서, README를 고쳤다(2026.10.7).
- 기획서 12절의 소라 대사 9번("2권에서 배운 거다")은 2권을 말한다. 2권은 한국어판뿐이라 외국 고객은 하지 못했다. 고치거나 뺀다. 5번("1권에선 안 그랬는데")은 1권을 한 고객에게만 통한다.
- 번역 시험의 원문에 서로 어긋나는 줄이 있다. 진도 바닷길이 "1년에 몇 번 갈라진다"와 "봄에 며칠만 열린다". 원 자료로 확인해 하나로 맞춘다.
- 번역 시험 원문의 해, 높이, 가는 길은 기억에 기대어 적은 초안이다. 원 자료로 확인하지 않았다.

## 6. 일하는 법

- 화면을 그림 파일로 찍을 때는 크롬을 머리 없이 띄운다. 시험판 주소 끝에 `#near` 나 `#shot` 을 붙이면 그 장면에서 시작한다. 윈도우의 크롬은 창 너비를 500픽셀 아래로 줄이지 못한다. 그래서 700픽셀로 찍고 가운데 420픽셀을 잘라 낸다.

```bash
chrome --headless=new --hide-scrollbars --allow-file-access-from-files --window-size=700,832 --virtual-time-budget=4000 --screenshot=docs/mock/overlay-3.png "file:///<저장소 경로>/docs/overlay-proto.html#shot"
```

- 눈에 띄는 일을 하나 마치면 `docs/바뀐-것들.md` 의 그날 맨 위에 한 줄을 더하고, 같은 커밋에 넣는다.
- 깃허브에 올리기 전에 매번 사용자에게 묻는다.
- 저장소는 나중에 공개한다. 비밀값, 이메일 주소, 개인 경로를 넣지 않는다. 커밋 전에 `git grep` 으로 훑는다.
