# 그래픽 발주서 8: 서울역에서 명동까지의 그림 7장

새 기획의 둘째 쪽 "서울역 → 명동"에 쓸 그림을 주문했다. 사용자의 말(2026.10.11): "명동 지어", "ㅇㅇ 그대로 지어".

- 쓴 날: 2026.10.11. 받은 날: 2026.10.11
- 그리는 손: 챗GPT의 그림 그리기. Codex CLI로 넣었다(`tools/art-order.sh`).
- 주문한 것: 7장. 모두 한 번에 받았고 다시 주문한 것은 없다. 일곱 장을 한꺼번에 넣어 2분 안에 왔다.
- 그림체: 색연필과 크레용의 그림일기(P4, `docs/art-order-7.md`). 참고 그림은 `assets/codex/order7-scene-p4/scene-p4.png` 하나다.
- 둔 곳: `docs/trip/art/` 에 960×640의 WebP(품질 82)로. 한 장에 229 → 271KB, 일곱 장이 1.8MB다.

## 1. 주문한 7장

| 파일 | 걸음 | 묘사 |
|---|---|---|
| `line4-platform` | 방면 고르기, 타기 | 지하철 타는 곳. 양쪽의 승강장 안전문 위에 하늘색 띠(4호선의 색). 천장의 안내판 둘이 왼쪽과 오른쪽을 화살표로 가리킨다 |
| `md-exit` | 출구 고르기 | 지하 대합실. 땅 위로 올라가는 계단 셋, 계단마다 숫자 없는 노란 번호판. 지하 가게들 |
| `md-wrong` | 틀린 출구 | 가게가 드문 찻길 옆 오르막. 길 끝에 산과 전망 탑. 버스 한 대 |
| `md-a` | 찍기(거리 들머리) | 명동 거리의 들머리. 차 없는 거리, 양쪽의 가게 건물과 색색의 간판, 오른쪽 앞에 출구의 유리 지붕 |
| `md-b` | 찍기(거리 한가운데) | 길거리 음식 수레의 줄. 거리 끝 왼쪽 멀리 산 위의 탑 |
| `md-c` | 찍기(옆 골목) | 좁은 골목. 화장품 가게의 분홍 차양, 양말 좌판, 머리 위의 전깃줄과 등 |
| `md-eat` | 먹기 | 계란빵을 든 두 손. 뒤에 수레의 철판과 빨간 차양 |

## 2. AI에 넣은 문장

앞머리는 `assets/codex/order8/_head.txt` 다. 발주서 7의 앞머리(`_head-p4.txt`)에서 달라진 것은 하나다. 발주서 7은 먼저 받은 그림의 구도를 지키며 그림체만 바꾸는 주문이라 참고 그림이 둘이었고, 이번은 새 장면이라 그림체의 참고 그림 하나만 넣고 "참고 그림의 장면을 다시 그리지 않는다"고 썼다.

장면마다의 문장은 `assets/codex/order8/<이름>.txt` 에 있다. 화면이 그림에 기대는 곳은 둘이다.

- `md-b`: "탑은 반드시 그림의 왼쪽에 있다. 오른쪽 하늘에는 아무것도 없다." 2004년의 사진에는 탑이 오른쪽에 있고 명동에서는 왼쪽에 보인다는 것이 이 쪽의 단서다.
- `line4-platform`: 안내판의 화살표가 왼쪽과 오른쪽을 가리킨다. 화면의 단추도 왼쪽이 사당 · 오이도 방면, 오른쪽이 진접 · 불암산 방면이다. 실제 승강장에서 어느 쪽이 어느 방면인지는 보지 않았다.

## 3. 받고 확인한 것

| 확인 | 결과 |
|---|---|
| 그림체가 공항 쪽의 9장과 한 식구인가 | 그렇다. 색연필의 비스듬한 결, 갈색 윤곽선, 밝은 색 |
| 글자, 숫자, 상표가 없는가 | 없다. 간판은 그림 기호(옷, 양말, 포크, 컵)와 색 띠다. 출구의 번호판은 노란 네모뿐이다 |
| `md-b` 의 탑이 왼쪽에 있는가 | 그렇다 |
| `md-a`, `md-c` 에 탑이 없는가 | 없다 |
| `md-eat` 의 소매가 하늘색인가 | **아니다.** 짙은 파랑으로 왔다. 그대로 쓴다. 유이의 겉옷(하늘색)과 맞추려면 이 한 장을 다시 받는다 |
| `md-eat` 에 탑이 보이는가 | 가운데에서 조금 왼쪽에 작게 보인다. 주문하지 않은 것이다. 단서와 어긋나지 않는다 |

## 4. 다시 주문하는 법

주문 문장과 받은 원본은 `assets/codex/order8*/` 에 있다. 이 폴더들은 커밋하지 않는다.

```bash
bash tools/art-order.sh assets/codex/order8-md-eat assets/codex/order8/md-eat.txt md-eat.png assets/codex/order7-scene-p4/scene-p4.png
```

받은 그림을 줄인다.

```bash
python -c "from PIL import Image; Image.open('assets/codex/order8-md-eat/md-eat.png').convert('RGB').resize((960,640), Image.LANCZOS).save('docs/trip/art/md-eat.webp', 'WEBP', quality=82, method=6)"
```
