# 게임 만드는 도구 이야기 (2026.10.13)

2026.10.13에 사용자와 나눈 이야기를 모은 문서다. 다른 게임이 무엇으로 만들어졌는지, 엔진과 장터가 어떻게 다른지, 그것이 팔도 한량(3권)에 무슨 뜻인지를 적었다.

읽는 법: **확인**이라 적은 것은 그날 누리집을 열어 읽은 것이고 출처가 맨 아래에 있다. **기억**이라 적은 것은 찾아보지 않고 답한 것이라 틀릴 수 있다. 값이나 한도를 믿고 움직이기 전에 공식 안내를 다시 본다.

## 1. 한 줄 요약

- Until Then 같은 게임(2D 그림을 3D 공간에 세운 옆걸음 게임)은 Godot 4가 가장 맞다.
- Usuimo 같은 게임(방 한 칸에 움직이는 인물)은 엔진보다 인물을 움직이는 도구(Live2D, Spine)를 먼저 정한다.
- 팔도 한량은 지금의 웹 화면 그대로 둔다. 손님이 손전화 브라우저에서 주소 하나로 열기 때문이다.
- 올릴 곳은 itch.io가 가볍고(등록비 없음), 스팀은 등록비 100달러에 실행 파일로 감싸는 일이 더 든다.

## 2. 살펴본 게임 둘

### Until Then (2024)

| 무엇 | 값 | 근거 |
|---|---|---|
| 엔진 | Godot 4.1 | 확인(만든 곳이 스팀 FAQ에 적음) |
| 만든 곳 | 필리핀의 Polychroma Games, 10명 남짓 | 확인 |
| 기간 | 2020 → 2024.6, 4년 | 확인 |
| 화면 | 2D 픽셀 그림을 3D 공간에 겹겹이 세운 2.5D 옆걸음 | 확인 |
| 용량 | 3GB | 확인(스팀 상점) |
| 어려웠던 것 | 게임의 꼴에 맞는 도구를 따로 만들어야 했다 | 확인(무슨 도구인지는 밝히지 않음) |

화면을 보고 헤아린 것(확인하지 못함): 걷는 맛은 3D 카메라와 시차에서, 분위기는 엔진이 입히는 빛과 초점 흐림에서 나온다. 손수 지었다는 도구는 긴 대화와 연출을 짜는 편집기일 공산이 크다.

### Usuimo (NLCH)

| 무엇 | 값 | 근거 |
|---|---|---|
| 엔진 | RPG Maker | 확인(만든 이가 itch.io 정보 칸에 적음) |
| 기기 | 윈도우, 맥, 리눅스, 안드로이드 | 확인 |
| 용량 | 체험판 1.2 → 1.4GB | 확인 |
| 값 | 15달러. 스팀에도 있다 | 확인 |
| 말 | 한국어, 일본어, 중국어를 비롯해 13개 | 확인 |
| AI | "No generative AI was used"라고 밝힘 | 확인 |

헤아린 것(확인하지 못함):

- RPG Maker 가운데 MV나 MZ일 것이다. 네 기기로 함께 낸 것이 그 근거다.
- 방 안의 인물은 Live2D나 Spine 같은 2D 뼈대 애니메이션을 플러그인으로 올린 것이다.
- 실시간 전투는 플러그인을 손수 짠 것이다.
- 확실히 알려면 체험판 속의 파일을 본다. MV는 `www/js/rpg_core.js`, MZ는 `js/rmmz_core.js`, Spine은 `.skel` 과 `.atlas`, Live2D는 `.moc3` 이 들어 있다.

이 게임은 성인용 내용이 든 판과 뺀 판(SFW, Safe For Work)을 다른 쪽으로 나눠 올린 것으로 보인다(댓글에서 읽음). 장터마다 성인용 게임의 규칙이 달라 순한 판을 따로 두는 것이 흔하다.

## 3. 엔진

### Godot 4

- 공짜이고 떼는 몫이 없다. 윈도우, 맥, 리눅스, 안드로이드, 웹으로 뽑아낸다(기억).
- 납작한 그림을 3D 공간에 세우는 부품이 기본이라 2D와 3D를 한 장면에 섞기 쉽다(기억).
- 장면(`.tscn`)과 스크립트(GDScript)가 모두 글로 된 파일이다. Claude가 직접 쓰고 명령줄로 돌릴 수 있다.
- 지금의 최신은 4.6이다(확인). 새로 시작하면 4.1을 쓸 까닭이 없다.
- 웹판은 엔진만 수십 MB라 손전화에서 처음 열 때 느리다(기억).
- 이 PC에는 깔려 있지 않다(2026.10.13에 확인).

Godot으로 만든 게임:

| 게임 | 판 | 근거 |
|---|---|---|
| Until Then | 4.1 | 확인 |
| Buckshot Roulette | 4.1.1(실행 기록에 찍힌 값). 한 사람이 만들어 400만 장 넘게 팔림 | 확인 |
| Slay the Spire 2, Halls of Torment, Backpack Battles | 4 | 기억 |
| Brotato, Dome Keeper, Cassette Beasts, The Case of the Golden Idol | 3 | 기억 |

### RPG Maker MV와 MZ

모두 기억으로 적었다.

- 코드를 몰라도 옛 일본풍 RPG를 만드는 도구다. MV는 2015년, MZ는 2020년에 나왔다. 값은 80달러쯤이고 한 번 사면 계속 쓴다.
- 탑뷰 타일 지도, 인물과 적과 물건의 자료 칸, 대화와 사건을 엮는 편집기, 차례로 싸우는 전투가 기본이다.
- MV부터 속이 웹 기술(자바스크립트)이다. 그래서 윈도우, 맥, 안드로이드, 아이폰, 웹으로 낸다.
- 기본에 없는 것은 자바스크립트 플러그인으로 더한다.
- Omori와 Fear & Hunger가 MV로 만든 게임이다.

### 엔진 견주기

| 엔진 | 잘 맞는 게임 | 걸리는 것 |
|---|---|---|
| Godot 4 | 2D와 3D를 섞는 옆걸음, 작은 팀의 2D 게임 | 웹판이 무겁다. Live2D의 공식 연결 도구가 없다 |
| Unity | 방 한 칸에 움직이는 인물을 두는 게임. Live2D와 Spine의 공식 도구가 가장 잘 갖춰짐 | 장면 파일을 글로 고치기 어려워 사람이 편집기를 만져야 한다 |
| Unreal | 3D 대작 | 2D 그림 위주의 게임에는 무겁다 |

| RPG Maker MV/MZ | 탑뷰 RPG | 다른 꼴의 화면은 플러그인으로 거의 새로 짠다 |
| Ren'Py | 대화와 선택지 중심의 게임. Live2D 기본 지원 | 걷는 장면과 실시간 전투가 어렵다 |
| 웹(직접 짓기, PixiJS) | 주소 하나로 여는 가벼운 게임 | 엔진이 주는 것(카메라, 빛, 편집기)이 없다 |

## 4. 인물을 움직이는 도구

모두 기억으로 적었다.

| | Live2D | Spine |
|---|---|---|
| 잘하는 것 | 얼굴과 상반신의 섬세한 움직임(숨, 깜빡임, 고개 돌리기, 머리카락) | 온몸의 동작(걷기, 앉기, 싸우기) |
| 값 | 작은 개인은 무료판으로 시작할 수 있다 | 편집기를 산다(기본판 70달러쯤) |
| 잘 붙는 엔진 | Unity, Ren'Py, 웹 | Unity, Godot, 웹 |

어느 쪽이든 인물 그림을 조각으로 나눠 그리고 뼈대를 심어야 한다. 이 일은 사람이 전용 편집기에서 손으로 하며 인물 하나에 며칠에서 몇 주가 든다. Claude가 그림 주문으로 대신하기 어렵다.

## 5. 올릴 곳

### itch.io

포럼 글과 비교 글에서 읽은 값이다. 공식 문서는 열지 못했다.

- `index.html` 이 든 ZIP 하나를 올리면 게임 쪽 안에서 바로 열린다. 등록비와 심사가 없다.
- 값은 공짜, 정가, "내고 싶은 만큼" 가운데 고른다. 장터의 몫은 기본 10%이고 0%까지 고칠 수 있다.
- 웹 게임의 한도: 푼 뒤 모두 500MB, 파일 하나에 200MB, 파일 수 1,000개쯤.
- AI를 썼는지 밝히는 칸이 있다(Usuimo의 쪽에서 확인).
- 스팀보다 손님이 훨씬 적다. 주소를 직접 알려 나누는 곳에 가깝다(기억).

### 스팀

모두 기억으로 적었다.

- 게임 하나에 등록비 100달러를 낸다. 본인 확인, 세금, 계좌 정보를 넣는다.
- 웹 게임은 실행 파일로 감싸야 한다(Electron 같은 것으로).
- AI로 만든 그림을 썼는지 밝히는 칸이 있다.
- 세로 화면의 손전화 게임과는 결이 달라 PC 창에서 어떻게 보일지를 따로 짜야 한다.

계정을 만들고 등록하는 일은 사용자가 직접 한다.

## 6. 팔도 한량에 주는 뜻

- **엔진을 옮기지 않는다.** 손님은 손전화 브라우저에서 주소 하나로 연다. 지금의 게임은 그림까지 3MB 안팎이고, Godot의 웹판은 엔진만 수십 MB다.
- **Until Then에서 가져온 것은 시차다.** 2026.10.13에 명동 거리를 세 겹(먼 산과 탑, 가게들, 앞의 나무)으로 받아 견본을 지었다. 먼 겹은 0.44배, 앞의 겹은 1.3배의 빠르기로 밀린다. 여는 곳은 `http://localhost:8319/water/?step=mdShoot`, 주문의 기록은 `docs/art-order-12.md` 다. 나머지 일곱 장면을 세 겹으로 받을지는 정하지 않았다.
- **빛과 초점 흐림은 가져오지 않는다.** 엷은 수채 그림체와 결이 다르다.
- **Usuimo의 화면 짜임은 지금의 것과 같다.** 큰 배경 그림 한 장 위에 인물을 얹고 누를 곳을 둔다. 다른 것은 인물의 움직임이다. 유이는 네 컷을 돌려 걷는다.
- **유이에게 숨쉬기와 깜빡임을 주려면** 지금의 웹 화면에 Spine이나 Live2D의 재생기를 붙이면 된다. 다만 그림을 조각으로 다시 받고 사람이 뼈대를 심어야 한다.
- **itch.io에 올리려면 둘을 손본다.** `docs/water/` 가 `../trip/`, `../compare/`, `../assets/` 의 파일을 읽으므로 그 폴더들을 함께 묶는 꾸러미를 만든다. 그림이 모두 AI로 만든 것임을 밝힌다.
- **엔진을 옮길 만한 때는** 스팀이나 앱 장터에 내려받는 게임으로 내기로 정할 때다. 그때는 웹판의 약점이 사라진다. Claude와 함께 짓는다면 장면까지 글인 Godot이 Unity보다 낫다.

## 7. 정하지 않은 것

- 나머지 일곱 장면을 세 겹으로 받을지.
- itch.io나 스팀에 올릴지, 올린다면 언제인지.
- 유이를 뼈대 애니메이션으로 바꿀지.
